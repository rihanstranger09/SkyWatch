SkyWatch — ISR imagery processing lines Event-driven · containerised worker · EO imagery exploitation

From raw pixels
to insight,automatically.

An event-driven ISR processing line: an electro-optical collection lands in the collection store, the queue buffers the event, and a container-image worker computes the terrain indices (NDVI and NDWI), publishes a Cloud-Optimized GeoTIFF product plus a preview render, and records bounds, CRS, provenance and index statistics in DynamoDB.

Collection store · SQS + DLQ · container worker (rasterio + GDAL) · product store · DynamoDB · CloudWatch · GitHub Actions.
